    Pilih Layout Halaman

    Cara Pakai
    1. Tombol ⊞ kanan bawah membuka daftar halaman: tambah halaman baru (pilih layout), ubah urutan (↑↓), ganti nama, atau hapus.
    2. Isi halaman langsung di kartunya: klik area bergaris putus-putus untuk foto, klik teks untuk mengetik (contoh dalam [kurung] hilang otomatis), klik area video untuk menempel tautan YouTube.
    3. Daftar Isi menyusun dirinya sendiri dari daftar halaman — ganti nama halaman di panel untuk mengubah judul di Daftar Isi.
    4. Semua tersimpan otomatis di browser ini. Untuk cadangan atau pindah komputer: Simpan Berkas Proyek, lalu Buka Proyek… di tempat lain.
    5. Selesai? Unduh Majalah menghasilkan satu file HTML siap dibagikan. Ikon unduh di tiap kartu menyimpan kartu itu sebagai PNG untuk medsos (perlu internet saat pertama dipakai).
